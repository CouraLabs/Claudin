# Theme assets

The `*.json` files in this folder originate from
[`anomalyco/opencode`](https://github.com/anomalyco/opencode) at `packages/tui/src/theme/assets`
(MIT License, Copyright (c) opencode contributors).

The dark palettes were adjusted so that no two semantic or surface roles share a color and every
foreground role keeps readable contrast against the surfaces. `vesper.json` is the default theme.
